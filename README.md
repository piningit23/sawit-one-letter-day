# One Letter Day — C

My entry for the make.fun competition "One Letter for Your Day": a program that writes exactly one letter to `/output/entry.txt`. I chose **C** — for **caffeinated**: a day run entirely on coffee. Jittery, bright-eyed, slightly trembling, but somehow getting everything done. Vivid, funny, and honest — the kind of day you describe to a friend in one word.

## Run it

```sh
python3 main.py
```

This writes exactly `C` (one byte, no trailing newline) to `/output/entry.txt`.
